## 0. 项目现状与落地前提（重要，避免返工）

1. **地图尚无"点击弹资讯"交互**
   现有 `src/components/charts/PolicyMap.vue` 仅用 ECharts `map:'china'` 渲染按"政策数量"着色的全国地图，交互只有 `tooltip`（显示数量）。**并没有点击省份展示资讯的逻辑**。因此"地图点击联动"是**新增** click 事件，而非改造旧逻辑——下文第 3 节据此设计。

### 1.2 核心量化维度 · 提取规则

> 通用：从 `assets/<类别>/<geoName>/*.docx`(或 .doc/.pdf) 抽取**全文纯文本**后，用关键词定位 + 正则捕获 + 人工复核。以下正则为"初筛"，命中后必须人工确认上下文，避免把"子女护理假"误抓成"配偶护理假"。

**① 独生子女父母护理假天数（最关键）**
- 关键词：`独生子女` + `父母` + (`护理假`|`陪护假`|`照料假`)
- 正则（Python）：
  ```python
  care_leave = re.search(
      r'(?:独生|独生子女).{0,10}?父母.{0,8}?(?:护理|陪护|照料).{0,4}?假.{0,12}?(\d{1,2})\s*天',
      text)
  days = int(care_leave.group(1)) if care_leave else None
  # 是否带薪：在同一句/邻近句检索
  paid = bool(re.search(r'(?:工资|薪金|待遇).{0,6}?(?:照发|不变|带薪|支付)', nearby))
  ```
- 归一化：`每年不少于十五日` → 15；`十日` → 10；无明确天数但写"应当给予护理假"→ 记 `days=None, note='有假无明确天数'`。
- 缺失：该省条例未规定 → `null`，卡片显示「—（未规定）」。

**③ 高龄津贴起始年龄 + 月标准**
- 起始年龄：`高龄津贴.{0,20}?(\d{2})\s*周岁` → 80/70/90…
- 月标准：`高龄津贴.{0,30}?(?:每人|每月|月).{0,8}?(\d{1,4})\s*元` → 存文本如 `"≥80岁:80元/月"`（避免不同年龄段多档被压成单值）。
- 注意：部分省按年龄分档（80/90/100 三档），建议存**文本**而非单数值。

**⑤ 免费/优惠乘坐公共交通起始年龄**
- `((?:免费|优惠|减半).{0,6}?乘坐.{0,14}?(?:公交|公共汽车|城市公共客运|轨道交通)).{0,10}?(\d{2})\s*周岁`
- 捕获不到"周岁"但写"满六十岁" → `年满|满\s*(\d{2})\s*岁`。

**⑥ 免费/优惠进入公园·景区·场馆年龄**
- `((?:免费|免|优惠).{0,4}?进入.{0,16}?(?:公园|景区|风景名胜|公共文化设施|体育场馆|博物馆|纪念馆)).{0,10}?(\d{2})\s*周岁`

**⑦ 失能/养老服务补贴**
- 布尔：`失能.{0,6}?老年人.{0,10}?(?:护理补贴|照护补贴)` 或 `养老服务补贴` 命中即 `True`。
- 标准：邻近句捕获金额，存文本（如 `"重度失能:100元/月"`）。

**⑧ 长期护理保险试点**
- 布尔：`长期护理保险` 且邻近 `试点` → 命中。
- 试点城市：`long_term_care` 附近提取地级市名（可用中国地市名单做实体匹配）。无国家试点但省级自选试点的，单独标注。

**⑨ 百岁老人长寿补贴**
- `百岁.{0,6}?老年人.{0,10}?(?:长寿|保健|营养|生活).{0,4}?补贴` → 捕获金额存文本；多数省有，差异在 100–500 元/月。

### 1.3 准量化/定性维度 · 提取要点

- **#10 老年人定义年龄**： national 《老年人权益保障法》第2条为 60 周岁，地方实施办法通常沿用。提取 `老年人.{0,6}?指\s*(\d{2})\s*周岁`；抓不到即默认 60，并在备注标注"沿用国家法"。
- **#11 就医优待年龄**：`优先就诊|就医绿色通道|设立老年病科` 邻近的年龄阈值。
- **#12 意外险补贴**：`老年人.{0,6}?意外伤害.{0,6}?(?:保险|统保|补贴)` + 是否"政府出资/财政购买"。
- **#13 适老化改造**：`家庭适老化改造` + 是否"补贴/免费/政府买单"及对象（低保/失能）。
- **#14 法援门槛**：`老年人.{0,10}?法律援助.{0,10}?(?:免予|无需|不受).{0,10}?经济困难审查`。
- **#15 赡养探望**：检索"常回家看看""探望""照料"是否入法及有无"批评教育/法院介入"等罚则。

### 1.4 提取工程化约定

- **数据源**：`assets/<类别>/<geoName>/*.docx`（.doc 须先转 docx；.pdf 用 pdfplumber）。
- **工具链**：`python-docx` 提文本 → 正则初筛 → 输出 `raw_extract.json`（含命中片段供人工复核）→ 人工修正后写入 `elderlyLawData.ts`。
- **缺失值约定**：统一 `null`，卡片渲染为「—」+ 灰字"未明确规定"，**绝不臆造 0 或默认值**。
- **数值语义**：护理假"天数越多越好"、优待"起始年龄越小越好"——在 `DimensionMeta.higherIsBetter` 标注，用于地图着色与排序。
- **可运行抽取脚本骨架**（真实可用，跑通样例见第 5 节）：
  ```python
  from pathlib import Path
  from docx import Document
  import re, json

  ASSETS = Path("assets")
  rules = {  # dimension_key: regex
      "careLeaveDays": r"独生子女.{0,10}?父母.{0,8}?护理假.{0,12}?(\d{1,2})\s*天",
      # ... 其余维度同上
  }

  def extract_doc(path: Path) -> dict:
      text = "\n".join(p.text for p in Document(path).paragraphs)
      out = {}
      for key, pat in rules.items():
          m = re.search(pat, text)
          out[key] = int(m.group(1)) if m else None
      return out

  result = {}
  for cat in ["省","自治区","直辖市","特别行政区"]:
      for prov in (ASSETS/cat).iterdir():
          docs = list(prov.glob("*"))
          result[prov.name] = {"docs": [d.name for d in docs],
                               "raw": extract_doc(docs[0])}
  json.dump(result, open("raw_extract.json","w"), ensure_ascii=False, indent=2)
  ```

## 3. 地图点击联动 + 卡片渲染逻辑

### 3.1 改造 `PolicyMap.vue`：新增 click → emit `select`

在 `loadMap()` 注册地图后拿到 chart 实例并绑定事件（关键改动，原文件无此逻辑）：

```ts
// PolicyMap.vue <script setup> 内
const emit = defineEmits<{ (e:'select', geoName:string):void }>()

let chart: echarts.ECharts | null = null
// BaseChart 暴露实例，或在 PolicyMap 内自行 init。若用 BaseChart，需给它加 @ready="onReady"
function onReady(inst: echarts.ECharts) {
  chart = inst
  chart.on('click', (params: any) => {
    if (params.componentType === 'series' && params.name) {
      emit('select', params.name)          // params.name 即 GeoJSON 全称，如 "内蒙古自治区"
    }
  })
}
// 高亮选中省（可选增强）
watch(() => props.selected, (name) => {
  chart?.dispatchAction({ type:'downplay', seriesIndex:0 })
  if (name) chart?.dispatchAction({ type:'highlight', seriesIndex:0, name })
})
```

> 若 `BaseChart.vue` 用 `echarts.init` 封装，请给它暴露一个 `@ready` 事件传出实例；否则直接在 `PolicyMap.vue` 内 `echarts.init` 更易控制。
> **注意**：地图 `params.name` 是 GeoJSON 全称，与 `assets/` 文件夹名一致，可直接作查表键，**无需转换**。

## 4. 数据结构设计

采用**"维度元数据 + 省份记录"双表结构**，让卡片、排序、筛选、地图着色全部数据驱动，新增/删减维度只改元数据，不动组件。

### 4.1 维度元数据（驱动一切）

```ts
// src/data/elderlyLawData.ts
export type DimType = 'number' | 'boolean' | 'enum' | 'text'

export interface DimensionMeta {
  key: string            // 数据字段名，如 'careLeaveDays'
  label: string          // 展示名，如 '独生子女父母护理假'
  type: DimType
  unit?: string          // '天' | '周岁' | '元/月'
  group: 'core' | 'more' // 核心卡 / 更多维度（用于二次删减）
```
